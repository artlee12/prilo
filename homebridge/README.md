# Prilo для Homebridge

Плагин добавляет переключатель питания Windows-ПК в Apple «Дом». Включение передаёт Wake-on-LAN, а выключение переключателя блокирует Windows через приёмник Prilo 0.10 (приёмник 0.9 с этим плагином выключает ПК). Мост и ПК должны быть в одной локальной сети. Мост должен работать и тогда, когда ПК выключен.

1. Установи [Homebridge](https://github.com/homebridge/homebridge/wiki) на Mac или другой постоянно работающий компьютер. В терминале этого компьютера выполни `npm install -g /полный/путь/homebridge-prilo-0.7.0.tgz`. Используй ту же установку Node.js, что и Homebridge.
2. В Prilo на Mac подключи профиль ПК и выбери его в боковой панели. В разделе «Питание» раскрой «Wake-on-LAN», проверь MAC и Broadcast одного адаптера (их показывает пункт «Данные для ручного подключения…» в меню Prilo в трее Windows) и нажми «Скопировать для Apple „Дома“».
3. В редакторе JSON Homebridge вставь скопированный объект как элемент массива `accessories`. Для каждого ПК добавь отдельный объект. Сохрани конфигурацию и перезапусти Homebridge.
4. В Apple «Доме» на iPhone добавь аксессуар и отсканируй QR-код **моста Homebridge**. Если мост уже добавлен, новый переключатель появится после перезапуска Homebridge.

Скопированные данные содержат отдельный код питания. Не публикуй их. Для блокировки должен отвечать приёмник под Windows. Если он закрыт, переключатель показывает ПК как недоступный по сети или выключенный. После Wake-on-LAN переключатель показывает ожидание запуска до 45 секунд.

Wake-on-LAN после полного выключения зависит от BIOS и Ethernet-адаптера. Проверь пробуждение из сна, затем отдельно попробуй из полного выключения. Если прошивка не умеет поднимать ПК из полного выключения, команда включения из этого состояния не сработает.
